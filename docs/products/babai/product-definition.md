# Product Definition

## Current answer

Core conceptual domain:

`Business/Merchant → Catalog/Inventory → Customer → Conversation → Order → Payment → Fulfillment → Staff Operations`

The product should preserve the business-owned customer relationship and WhatsApp identity while providing the operating layer.

Experience principle:

- **Web = see everything.**
- **WhatsApp = know what needs attention and act immediately.**

The same identity/context should move between WhatsApp and web without losing context.

## Current scope

Restaurant-first MVP with WhatsApp ordering/management, catalog/menu, staff operations, human takeover, payments and provider-agnostic fulfillment where enabled.
