# Candidate-only asset review

This directory contains five user-supplied JPEGs copied on 2026-09-21 for
internal website/template review only. The files remain unapproved candidates;
they do not replace the approved repository branding assets under
`assets/branding/logo/`.

`provenance.json` records the original temporary path, repository copy,
SHA-256, dimensions, background/alpha observations, responsive-use notes and
draft alt text for those source JPEGs. No source JPEG was generated,
re-encoded, cropped or otherwise transformed. Do not infer trademark clearance,
licensing, final brand approval, public-asset approval or deployment permission
from these copies.

The `logos/` subdirectory contains four locally authored transparent SVG
concepts for the internal founder decision packet. They are exploratory
directions only (mascot + spark, restaurant operator + spark, wordmark + spark,
and a NEKURAMA-endorsed BABAI lockup). `provenance.json` records their intent,
source anchors, contrast guidance, aspect/crop guidance and alt text. They do
not replace approved branding assets and must not be published or treated as
trademark, licensing or final-approval evidence.
